# Tower Soft V2 v2.0.0

First clean Tower Soft V2 release snapshot for the new repository.

## Highlights

- Rebuild app in `tower_rebuild/` is the primary deploy target.
- SQL Lab, Maintenance, Consumables, Draw Finalize, and Development rebuild flows are included.
- Full draw datasets use the newer foldered `data_set_csv/` layout.
- Migration, release preflight, network smoke, and full-flow smoke tools are included.

## Dataset Layout

Full draw CSVs used by SQL Lab are stored like this:

```text
data_set_csv/
  <draw-folder>/
    <draw>.csv
    <draw>_Z1/
      <draw>_Z1.csv
    <draw>_Z2/
      <draw>_Z2.csv
```

Example:

```text
data_set_csv/FLOWP4045/FLOWP4045F1.csv
data_set_csv/FLOWP4045/FLOWP4045F1_Z1/FLOWP4045F1_Z1.csv
```

Meaning:

- the top-level CSV inside the draw folder is the full dataset
- nested `_Z*` folders contain zone snapshots
- SQL Lab reads the full draw CSVs, not the zone snapshots
